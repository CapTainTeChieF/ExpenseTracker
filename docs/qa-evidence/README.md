# Local QA Evidence

Generated reports appear here after running `npm run qa:integration`:

- `qa_api_result.json` — case outcomes and local timing values on success
- `qa_failure.json` — error and debugging detail if the runner stops

These files are intentionally not pre-populated. Do not use fake PASS records.

**Privacy:** Reports should contain test-only identifiers; avoid collecting raw session cookies, passwords, bank credentials, personal financial data or private auth tokens. Store and share only sanitized logs and screenshots.
